## 10. Конвенции работы

- Тексты кейсов: .txt файлы — источник правды (course-constructor-content.txt, raspisanie-case.txt, oplata-case.txt, obuchenie-case.txt)
- Стиль: humanizer (без длинных тире, живой язык, женский род); «не только X, но и Y» и «от X до Y» — избегать
- Метрики: только реальные цифры
- Визуализации: SVG в SaaS-стиле (белые карточки, #E5E6EB границы, #9670E8 акцент, без теней)
- Анимации: IntersectionObserver + CSS transitions, без GSAP в кейсах
- Карусель-паттерн: см. раздел 3 (одинаковый во всех кейсах, carGo инлайном)
- Скрины внутри блоков: radius 16, zoomable; стендэлоны: обводка #252525 12px, radius 24, margin 12px auto
- Гипотезы: карточки 💡; челлендж: список 📌; валидация-списки: ✅ (класс validation-checks)
- Обновление сайта: git push → GitHub Pages обновится автоматически за 1-2 мин
