### Стиль всех кейс-страниц
- Заголовки блоков (cell-kicker): 24px, primary, без КАПСа, font-weight 500
- Текст (cell-text.primary): primary цвет; списки 16px primary
- Блоки: cell s12, на всю ширину, gap 12px (bento grid)
- Скругление блоков: var(--radius) = 24px
- Скругление скринов внутри блоков: 16px
- Скрины-стендэлоны: обводка #252525 12px наружу (outline), ширина calc(100%-24px), margin 12px auto
- Навигация: scroll-spy в app.js (IntersectionObserver), маркер-точка ink слева на -14px
- Зум картинок: класс .zoomable, лайтбокс в app.js (fixed overlay, Esc/клик для закрытия)
- В конце каждого кейса: блок «Другие кейсы» (слайдер с 4 карточками, исключая текущий)
- #body {display:contents} — чтобы блоки были прямыми детьми bento grid
